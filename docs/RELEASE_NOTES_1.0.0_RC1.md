# CHEBURNET 1.0.0 RC1

> [!WARNING]
> Этот выпуск заменён [CHEBURNET 1.0.0 RC2](https://github.com/Jacksony100/CHEBURNET/releases/tag/v1.0.0-rc.2). Для новой установки используйте RC2.

Первый публичный кандидат в релиз CHEBURNET: один переносимый EXE для
управляемого запуска проверенного движка `winws` на Windows 10/11 x64.

> **Статус кандидата.** Автоматические проверки пройдены, но интерактивная
> проверка на чистых виртуальных машинах Windows 10 и 11 остаётся обязательным
> условием перед стабильным выпуском.

## Главное

- встроенный исходный выпуск Flowseal `zapret-discord-youtube` **1.10.1**;
- динамический каталог стратегий без жёстко заданного количества;
- защищённая версионная рабочая среда и откат на известную рабочую версию;
- обновления программы и движка с подписью ECDSA P-256 и безопасным отказом;
- четыре режима игрового фильтра;
- локальные журналы и диагностика без телеметрии;
- исправленный вывод Unicode и строгая проверка ACL открытого файла журнала.

## Что скачать

- `CHEBURNET.exe` — единственный файл, необходимый обычному пользователю;
- `CHEBURNET.exe.sha256` — контрольная сумма программы;
- `cheburnet-payload-1.10.1.cbpkg` — подписываемый пакет обновления движка;
- `update-manifest.json` и `.sig` — манифест и отдельная подпись ECDSA;
- уведомления и лицензии — исходные условия сторонних компонентов.

EXE в этом кандидате **не имеет подписи Authenticode**. Это явно не скрывается:
проверяйте SHA-256 и скачивайте файлы только с этой страницы. Манифест
обновлений подписан отдельным встроенным ключом и проверяется с безопасным отказом.
