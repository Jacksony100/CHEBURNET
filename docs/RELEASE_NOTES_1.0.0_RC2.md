# CHEBURNET 1.0.0 RC2

Русифицированный кандидат в релиз CHEBURNET для Windows 10/11 x64. Обычному
пользователю по-прежнему нужен только один файл — `CHEBURNET.exe`.

> **Статус кандидата.** Сборка и автоматические проверки пройдены. До объявления
> стабильного выпуска остаётся интерактивная проверка на чистых виртуальных
> машинах Windows 10 и 11. EXE пока не имеет подписи Authenticode.

## Что изменилось после RC1

- интерфейс, CLI, диагностика, журналы, README, документы, шаблоны GitHub,
  иллюстрации и метаданные Windows переведены на русский язык;
- внутренние значения конфигурации сохранены без изменений для обратной
  совместимости, но пользователю показываются русские названия режимов;
- адрес подписанного манифеста привязан к тегу `v1.0.0-rc.2`, потому что GitHub
  не включает предварительные выпуски в адрес `/releases/latest`;
- улучшена иконка приложения и оформление публичной страницы;
- сохранены все исправления безопасности и обновлений из RC1.

## Состав

- `CHEBURNET.exe` — программа для пользователя;
- `CHEBURNET.exe.sha256` — контрольная сумма программы;
- `cheburnet-payload-1.10.1.cbpkg` и `.sha256` — проверенный пакет движка;
- `update-manifest.json` и `.sig` — подписанные метаданные обновления;
- документы зависимостей и исходные тексты сторонних лицензий.

## Безопасность

Встроен неизменяемый выпуск Flowseal `zapret-discord-youtube` **1.10.1**.
Обновления принимаются только после проверки отдельной подписи ECDSA P-256,
схемы, версий, размера и SHA-256. Любая ошибка приводит к отказу без изменения
активной рабочей среды. Понижение версии запрещено.

EXE не подписан Authenticode: скачивайте его только с этой страницы и сверяйте
SHA-256 с опубликованным файлом `.sha256`.

## Проверки

Проверки кандидата:

- сборка Release с `/W4 /WX`: пройдена, 45 из 45 целей;
- автоматические тесты: пройдены, 33 из 33;
- соответствие стратегий upstream: пройдено, 84 из 84;
- регрессионные проверки безопасности: пройдены;
- отрицательные тесты пакетов обновления: пройдены;
- проверка лицензий: пройдена;
- чистая виртуальная машина Windows 10/11: ожидает ручной проверки, поэтому
  выпуск остаётся предварительным.

Интерактивная проверка на чистых Windows 10/11 пока не выполнена, поэтому этот
выпуск остаётся кандидатом, а не стабильной версией.
