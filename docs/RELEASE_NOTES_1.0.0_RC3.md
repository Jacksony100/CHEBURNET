# CHEBURNET 1.0.0 RC3

Русскоязычный кандидат в релиз CHEBURNET для Windows 10/11 x64. Пользователю
нужен только один файл — `CHEBURNET.exe`.

> **Статус кандидата.** Автоматические проверки пройдены. До стабильного
> выпуска остаётся интерактивная проверка на чистых виртуальных машинах
> Windows 10 и 11. EXE пока не имеет подписи Authenticode.

## Что изменилось после RC2

- стабильный канал теперь получает манифест только через GitHub
  `releases/latest/download`, который исключает предварительные выпуски;
- регрессионный тест запрещает случайно привязать production endpoint к RC;
- выпускные PowerShell-этапы совместимы с Windows PowerShell 5.1 и проверяются
  обычным CI до создания тега;
- подписанный манифест независимо проверяется встроенным открытым ключом до
  публикации файлов;
- GitHub Actions закреплены по SHA на Node.js 24-совместимых выпусках;
- интерфейс, документация, шаблоны GitHub и метаданные Windows остаются
  полностью русскоязычными.

## Состав

- `CHEBURNET.exe` — единственный файл, необходимый пользователю;
- `CHEBURNET.exe.sha256` — контрольная сумма программы;
- `cheburnet-payload-1.10.1.cbpkg` и `.sha256` — проверенный пакет движка;
- `update-manifest.json` и `.sig` — подписанные метаданные обновления;
- документы зависимостей и исходные тексты сторонних лицензий.

## Безопасность

Встроен неизменяемый выпуск Flowseal `zapret-discord-youtube` **1.10.1**.
Обновления принимаются только после проверки ECDSA P-256, строгой схемы,
версий, размера и SHA-256. Ошибка приводит к отказу без изменения активной
среды; понижение версии запрещено.

EXE не подписан Authenticode: скачивайте его только с этой страницы и сверяйте
SHA-256 с опубликованным файлом `.sha256`.
